日语语法复习 · たら / に / と / そうだ / 意志形

合并 11-25、11-26 两天 · 共 13 个语法点 · 按主题重组，非时间顺序

0111-25たら 的三套接法

会社で
山下：森さん、ちょっとそうだんしたいことがあるんですが、あした時間がありますか。
森：ええ。4時までだったら いつでも だいじょうぶですよ。
→ 到 4 点为止的话，随时都没问题。

前面是什么接法例
名词だったら学生だったら
名词＋助词だったら4時までだったら、明日からだったら
な形容词だったら静かだったら
い形容词かったら大きかったら
动词たら行ったら、買ったら
判据一句话：前面这个词要不要「だ」。
要 だ（名词、な形容词）→ 把 だ 换成 だったら；
不要 だ（い形容词、动词）→ 用 かったら ／ たら。

「です」测试：现场最快的判断法

在候选词后面加「です」，通就能接 だったら。

候选加 です能接 だったら
4時まで4時までです ✓✓
学生学生です ✓✓
静か静かです ✓✓
いつでもいつでもです ✗✗
だれでもだれでもです ✗✗
「です」和「だったら」是同一套逻辑：都是把一个“东西”拿来做判断。
なら 也守同一条规矩：4時までなら ✓ ／ いつでもなら ✗

0211-25でも 不是转折 + 疑问词＋でも 不能接 だ

这题选项里 B 的注释写「但是；不过」，那是 でも 单独作接续词时的意思。本句里它是 いつ + でも 的后半截。

看到“但是”就排除它，正好中招。
いつでも ＝ 随时（副词），不是“いつ + 助词でも”。

为什么 まで 能接、でも 不能

说法整段是什么判断
4時まで格助词贴在名词后，整段仍是名词性（回答“到几点”）✓ 受付は4時までです
いつでも固定副词（词典条目就是副词），回答“什么时候”✗ 受付はいつでもです
不是“助词能加、副词不能加”，而是：整段是不是一个“东西”。
疑问词＋でも 全族——いつでも／だれでも／どこでも／何でも——一个都不能接 だ。
它们是用来修饰后面谓语的（いつでも大丈夫），不是用来被判断的。

0311-25排序题：能塞进去 ≠ 能接上

当时排的「4時まで いつ でも だったら だいじょうぶ」——四个词位置全对，但 だったら 接不上 いつでも。

两步走：
① 先按意思排出顺序（谁是条件、谁是谓语、哪两个词该连成一个词）
② 再用接续验一遍（だったら 前面必须是要 だ 的那一类）

附：判据是“名词化”，不是“辞书形”

说法判断
行くだったら✗ 还是动词
行くことだったら✓ 加了 こと，成了“东西”

辞书形只是查词典那一栏（行く、食べる、大きい），名词没有辞书形这一说，所以它当不了判据； 名词化（套 こと／の／さ）才是真正的判据。

0411-26に 的两副面孔：用途 ／ 结果状态

① 用途：名词 ＋ に ＋ 使う

このレストランでは、料理に使う野菜を庭で育てています。
→ 这家餐厅在院子里种做菜用的蔬菜。

说法意思
料理に使う用于做菜
勉強に使う用于学习
何に使いますか用来做什么
方向别搞反：野菜を料理に使う（把蔬菜用于做菜）
を＝被使用的东西，に＝用途。中文“用蔬菜做菜”里的“用”是日语的反方向。

② 结果状态：名词／な形容词 ＋ に ＋ する

大切にします。→ 我会好好珍惜的。（收礼物时的标准答谢）

说法意思
大切にする当作重要的 → 珍惜
部屋をきれいにする把房间弄干净
無駄にする浪费
静かにする保持安静

四基础动词的分工

动词性质接 に 后
する做（人为改变）～にする ＝ 使变成／当作
なる变成（自然变化）～になる ＝ 变成……
ある有（无生命）～にある ＝ 存在于（场所）
いる在（有生命）～にいる ＝ 存在于（场所，人或动物）
大切にします 用现在时——表示“我今后会珍惜”，是承诺不是叙述，所以不能用 ました。

0511-26の 什么时候能替 が

「料理の使う野菜」为什么不成立——他的分析（使う野菜 是名词短语）是对的，问题在另一层。

の 可以进定语从句，但进去以后就变成 が

原句换成 が通不通
雨の降る日雨が降る日✓ 雨会下
私の書いた本私が書いた本✓ 我写的
料理の使う野菜料理が使う野菜✗ 菜不会使用
判断动作：看到 の，就读成 が。
通得过才能用 の。这道题一换成 が，料理 就成了“使用者”，语义直接崩掉。

三种 の 分清

用法例换成 が 之后
所属私の本✗ 私が本
修饰（名词＋名词）日本語の本—
从句主语替身雨の降る日✓ 成立

0611-26て形表原因，接情感词

ふじ山にはずっとのぼりたかったのですが、のぼることができて、うれしかったです。
→ 一直很想爬富士山，（这次）能爬上去，真高兴。

① のぼりたかった（心愿）→ ② できて（实现）→ ③ うれしかった（反应）
例句意思
会えて、うれしいです能见到你，很高兴
合格して、安心しました合格了，放心了
もらって、うれしかった收到了，很高兴
“因为某件事，心里产生了反应” → 用 て形连接。
这是日语最常见的情感表达方式。
为什么不是 から：から 要求前后是真正的因果。
✗ ずっと のぼりたかったから、のぼることができて…（“因为想爬，所以能爬上去”——想不会让你变得能）
✓ 毎日練習したから、のぼることができました

拆解：のぼるのが好きで（で＝并列）、のぼりたかった（たい的过去）、のぼることができて（可能＋ことができる）。

0711-26と 的两种身份：引用 ／ 条件

外国に住んでいる友達が けっこんすると 聞いたので、プレゼントを送ろうと 思う。
→ 听说住在国外的朋友要结婚了，所以想送份礼物。

と 后面接什么と 的作用例
聞く／言う／思う／答える引用（内容）けっこんすると聞いた
一般动词条件（如果／一…就）春になると花が咲く
先看 と 后面那个动词，身份立刻确定。
けっこんすると 看着像条件，但后面是 聞いた，所以是引用。

排序的三把锁

位置词依据
第 1 格友達が外国に住んでいる 修饰 友達，两者必须相邻
第 2 格けっこんするとと 前面必须有被引用的内容，聞いた 要接在后面
第 3 格 ★聞いたので原因句在结论之前
第 4 格プレゼントを送ろうと结尾是 思う，第 4 格必然是 ～（よ）うと——拆不开

友達がけっこんする 是被引用的小句子，从句主语用 が——与「木村さんが着ていたシャツ」「田中さんが送ってくれたカード」同一条规则。

0811-26意志形：一二三类 ＋ 六个例外

类别规则例
一类（五段）词尾 u → o 段 ＋ う書く→書こう、読む→読もう、話す→話そう、待つ→待とう、遊ぶ→遊ぼう、買う→買おう、取る→取ろう
二类（一段）去 る ＋ よう食べる→食べよう、見る→見よう、起きる→起きよう
三类する→しよう／来る→こよう勉強する→勉強しよう
长得像二类、其实是一类的六个（必背）：
帰る→帰ろう　入る→入ろう　走る→走ろう　 切る→切ろう　知る→知ろう　要る→要ろう
✗ 帰よう／入よう／走よう

意志形的三种用法

句型意思例
单独用自言自语“我要…”そろそろ寝よう。
～う／ようと思う打算プレゼントを送ろうと思う
～う／ようとする想要／正要出かけようとした時、電話が来た

礼貌体对应：意志形（書こう）↔ ましょう（書きましょう）。

0911-26きっと ＋ でしょう，不是 んです

森さんは 花が 好きだから、きっと よろこぶでしょう。
→ 森喜欢花，所以一定会很高兴吧。

んです 与 でしょう 的分工

んです／のですでしょう
作用说明、解释推测
回答什么为什么？会怎样？
常搭配どうして、～からきっと、たぶん、おそらく
例子風邪をひいたんです風邪をひくでしょう
きっと 是推量副词，不是“确定”。它只能配推测：でしょう／はずだ／にちがいない／と思う。
✗ きっと来るんです

关键：から 有两种角色

角色结构例
说明的理由理由 から ＋ 结论 んです足が痛いから、歩けないんです
推测的依据依据 から ＋ 推断 でしょう日曜日だから、店は込むでしょう
三个错项：
よろこぶそうです＝伝聞（听说），句子是推断出来的，没有信息来源。
よろこんだようです＝好像高兴了，过去时，生日还没到。
よろこびそうです 才是“看起来会高兴”——和 よろこぶそうです 只差一个假名。

1011-26なかなか ＋ 否定／会えない vs 会わない

最近、私は仕事がいそがしくて なかなか ともだちと 会えない。
→ 最近工作很忙，一直没能和朋友见面。

用法例句意思
＋ 否定なかなか来ない迟迟不来
＋ 肯定この店はなかなかいい这店相当不错
同一个词，看句尾定意思。句尾否定＝怎么也不；句尾肯定＝相当。

会えない 与 会わない

形式语法意思
会えない可能形（会える）的否定见不到（客观不允许）
会わない一般否定不见（主观不打算）

五段动词的可能形：词尾改え段 ＋ る

原形可能形否定
会う会える会えない
書く書ける書けない
読む読める読めない

同族否定呼应副词：あまり（不太）、全然（完全不）、少しも（一点也不）、めったに（很少）、とても（怎么也…不）。
与人见面：友だちと会う ✓　友だちに会う ✓（に 更强调朝向对方）。

1111-26中（ちゅう）vs とき／ごろ／間

今朝 さんぽ中に、かわいい ねこを 見ました。
→ 今天早上在散步途中，看到了一只可爱的猫。

词接续意思
中（ちゅう）名词 ＋ 中正在……的过程中（散歩中、会議中、授業中）
とき动词／名词＋の时候（散歩するとき、散歩のとき）
ごろ时间词 ＋ ごろ大约某时刻（3時ごろ）
間（あいだ）名词＋の＋間有起止的期间（夏休みの間）
ときに 并不是意思不对，而是接不上：
✓ 散歩のときに　 ✗ 散歩ときに（括号前面没有 の）

中 的两种读法

读法意思例
ちゅう某个动作正在进行会議中、授業中、営業中、散歩中
じゅう整个范围／整段世界中、一日中、家中

中 vs 中に：「散歩中、猫を見た」＝在散步这个状态里；「散歩中に、猫を見た」＝在途中某一刻。に 把过程切成一个时点，配一次性动作最自然。

1211-26によると ＋ そうだ（传闻框架）

母の話によると、私は小さいとき、この絵本が大好きだったそうだ。
→ 据妈妈说的话，我小时候非常喜欢这本绘本。

前半后半
によると（据……）そうだ（听说）
一对搭档，一个开一个收。
天気予報によると、明日は雨だそうだ。
によると 后面只能接传闻，不能接自己的判断：
✗ 母の話によると、私は行きたい
✓ 母の話によると、私は行ったそうだ

句中另外三个语法

部分规则
母の話名词＋の＋名词，可以多层叠（母の友だちの話）
小さいときい形容词直接接 とき，不用 の（名词才要：子供のとき）
大好きだったな形容词过去＝だった；そうだ 接的是 だった

好き・嫌い・上手・下手・ほしい 这一族都带 が，因为它们表状态与好恶，不是动作。

1311-26伝聞そうだ vs 様態そうだ：尾巴在不在

唯一要问的：そう 前面是“完整形”还是“词干”。

そう 前面是什么判断
完整的词形（该有的尾巴还在）听说（伝聞）
词干（尾巴被削掉了）看起来（様態）
词类完整形（听说）词干（看起来）
动词降るそうだ降りそうだ
い形容词おいしいそうだおいしそうだ
な形容词元気だそうだ元気そうだ
看 そう 前面最后一个字符：る／い／だ 还在 → 听说；没了 → 看起来。
三行是同一个动作：削掉尾巴 ＝ 只剩表面。

为什么是这个逻辑

  • 听说：把别人的一整句话原样转述，所以那句话是完整的。
  • 看起来：你只是看着外观猜，手里没有完整信息，所以只剩词干。

三对最小对比（读出声）

听说看起来
雨が降るそうだ雨が降りそうだ
このケーキはおいしいそうだおいしそうだ
田中さんは元気だそうだ元気そうだ
捷径：句子前面出现 によると、話では、天気予報では → 直接就是听说，不用再看词形。

14两天的错因归纳

错因类型当时怎么想岔的下次怎么防
① 位置塞得进去就以为对四个词顺序看着通，但 だったら 接不上 いつでも排完再用接续验一遍，能塞 ≠ 能接
② 看注释选词でも 的注释写“但是”，就当转折排除了注释只给一个义项，先看它在句中跟谁连
③ 用"主语"解释一切知道 の 能进从句，但没验"换回 が 后通不通"看到 の 就读成 が，通得过才能用
④ 有 から 就以为要“解释”把 きっと 当成“确定”，于是配了 んですから 可当“依据”，后面照样能接推测
⑤ 记词义不记条件なかなか 只记“相当”，没记“＋否定＝怎么也不”副词要连句尾要求一起记

15自测 12 题（覆盖两天）

先做完 12 题再对答案。

1. 4時まで＿＿＿、いつでも だいじょうぶです。
だったら　4時まで 加「です」通得过 → 名词性 → だったら。
2. 静か＿＿＿、勉強できます。
だったら　な形容词要 だ → だったら。
3. 大き＿＿＿、れいぞうこに 入りません。
かったら　い形容词不要 だ → かったら。
4. この野菜は 料理＿＿＿ 使います。
に　用途。「野菜を料理に使う」——を 是被用的东西，に 是用途。
5. プレゼントは 大切＿＿＿ します。
に　な形容词＋に＋する＝当作…对待；大切にする＝珍惜。
6. 友だちに 会え＿＿＿、うれしかったです。
て　て形表原因，接情感词（～て、うれしい）。
7. 雨が 降る＿＿＿ 聞きました。
と　と 后接 聞く＝引用（听说会下雨）。
8. 外国の 友だちに プレゼントを 送＿＿＿ 思います。
ろうと　送る（一类）→ 送ろう＋と＋思う＝打算送。
9. 花が 好きだから、きっと よろこぶ＿＿＿。
でしょう　きっと 只能配推测；んです 是说明，不是推测。
10. 忙しくて、＿＿＿ 友だちと 会えません。
なかなか　なかなか＋否定＝怎么也不、一直没能。
11. 今朝 さんぽ＿＿＿ に、ねこを 見ました。
中（ちゅう）　名词直接接 中；用 とき 要写「散歩のときに」。
12. このケーキは＿＿＿＿。（看起来很好吃）
おいしそうだ　様態：去掉 い，只剩词干。
