01授受三兄弟：あげる / くれる / もらう

判定只问两件事：东西有没有流向"我"，主语是给的人还是收的人。

句型主语是谁东西往哪走例句
あげる给的人我（或己方）→ 别人田中さんに本をあげた
くれる给的人别人 → 我田中さんが本をくれた
もらう收的人别人 → 我（我收到）田中さんに本をもらった
主语决定动词：主语是"给的人"就用 あげる / くれる；主语是"收的人"就用 もらう。
不能"田中当主语 + もらう"来表达"他送我"。

助词决定排除法

形式施予者的助词例句
～てくれるが田中さんが送ってくれた
～てもらうに（私が）田中さんに送ってもらった
不要过度推广：「小句子里不能用もらう」是错的。定语从句里照样能用，只要换主语：
田中さんが送ってくれたカード ／ 田中さんに送ってもらったカード　两句都成立。
另外 田中さんがもらった 本身也通——意思是"田中收到了"。

附带规则：定语从句里的主语用 が

  • ✓ 木村さんが着ていたシャツ
  • ✗ 木村さんは着ていたシャツ（は 不能在小句子里表主题）

02形式名词：ところ / こと

ところ 既能做实义名词（地方），也做形式名词；こと 基本只做形式名词。做形式名词时没有实义，只负责把前面的内容"打成名词"，好让后面的句型接上去——日语靠它们造出动词本身表达不了的语法意义。

ところ 的三层含义（核心意象＝"一个点"）

含义用法例句
空间上的点地方、位置静かなところ／先生のところ
时间上的点～ところだ（阶段）着いたところだ
话头上的点ところで（话说回来）ところで、明日の会議は？

～ところだ 的三个阶段

接续意思例句
辞书形 ＋ ところだ正要…（未开始）今から出かけるところです
ている ＋ ところだ正在…（进行中）今、食べているところです
た形 ＋ ところだ刚刚…（已完成）今、着いたところです
たところだ vs たばかりだ：ところ 卡得紧（就一两分钟），ばかり 松得多（上个月也算"刚"）。

こと 系：谁做决定

一次决定持续状态／规矩
自己～ことにする（我决定）～ことにしている（我习惯／自我规定）
客观～ことになる（结果定下来）～ことになっている（规定如此）
ひっこすことになりました 的重点在"结果变成这样"，说话人躲在结果后面，语气谦虚、不居功。
自己拍板的事才用 ことにしました。

になる / にする 的接续

前接词类形式例句
名词名词 ＋ になる大学生になる
な形容词な形容词 ＋ になる静かになる
い形容词い → く ＋ なる寒くなる
动词动词 ＋ こと ＋ になる引っ越すことになる
动词不能直接接 になる／にする。
✗ 引っ越すになる　✗ 食べるにする
✓ 引っ越すことになる　✓ 食べることにする

另一个「にします」：接名词时表示"就选这个"。コーヒーにします（我要咖啡）——与 ことにする 同源，只是接的是名词。

03修饰链：排序题全考这里

四种词接名词的方式

词类接法例句
い形容词直接接あまいくだもの／明るいシャツ
な形容词加 なきれいな花
名词加 の形のくだもの／あんな色のシャツ
动词（た形・辞书形）直接接着ていたシャツ／明日来る人
只有名词需要 の，动词完全不需要。
✗ 着ていたのシャツ　✓ 着ていたシャツ

动词修饰名词＝定语从句

动词的た形／辞书形／ない形都可以直接放在名词前，相当于"一个整句打包成形容词"。

[木村さんが着ていた] シャツ └── 一整个小句子 ──┘ ↑ 被修饰的名词
形式修饰名词意思
辞书形着るシャツ要穿的衬衫
た形着ていたシャツ（当时）穿着的衬衫
ている着ている人正穿着的人

な形容词连接：で 还是 に

后面接什么用哪个例句
形容词／并列句で静かでいい／静かで明るい部屋
动词（副词）に静かに話す／静かにドアを閉める
名词な静かな部屋
✗ 静かにいい　→　✓ 静かでいい　（に 只能修饰动词，不能修饰形容词 いい）
同型：きれいでいい、便利でいい。

排序题推演示例

① まるい + 形 + の → ② 赤くて + あまい → くだもの （什么样的形状） （什么颜色和味道） （中心名词）
  • あまい（い形容词原形）→ 只能直接接名词 → 必定最后一格（紧贴 くだもの）
  • 赤くて（て形）→ 必须往下连另一个形容词 → 只能站在 あまい 前
  • の → 必须紧跟名词 形，跑不掉

04てくる / ていく：方向感

视点固定在说话人此刻站的位置。

[对方那边] ──てくる（朝我来）──→ [我现在这里] ──ていく（离我去）──→ [别处]
形式意思例句
～てくる做完回来／朝我靠近先生に出してきました
～ていく做完离开／离我而去出していきました

てくる 的衍生义（高频）

用法例句意思
去去就回ちょっと行ってきます我出去一下
出现／开始雨が降ってきた下起雨来了
变化わかってきた开始明白了
口诀：去了还回来 → てくる；去了不回来 → ていく。

～に行く（去做某事）

动词ます形去ます ＋ に ＋ 行く 出します → 出し ＋ に ＋ 行く ＝ 出しに行く（去交）

行く 本身是持续动作，所以 行っています 可以表示"正在去"：今、出しに行っています。

瞬间动词 ＋ ている＝结果状态，不是"正在"。
宿題を出しています ＝ 已经交了／平时都交，不是"正在交"。
同型：結婚しています（已婚）、知っています（知道）。

05助词专题

しか ＋ 否定

形式句尾例句
だけ肯定一週間だけいられます
しか否定一週間しかいられません
去掉 しか 意思会反转：一週間いられません ＝ 待不了一周（连一周都不到）。
いられません 是 いる → いられる（可能形）→ いられない 的变化，意为"不能待"。

疑问词 ＋ でも / も

形式意思句尾要求
いつでも・どこでも・だれでも任何时候／任何地方／谁都可以肯定
どこからでも从任何地方都（でも 可加在助词后）肯定
どこにも・だれにも・なにも哪里都不／谁都不／什么都不否定

陷阱：いつまで（到什么时候）≠ いつまでも（永远）。

について vs のこと

形式语法角色后面还要助词吗
について复合助词（标记"关于"）不要
のこと名词短语（"…的事"）要，按动词选 を／が／は
  • ✓ 歴史について調べています
  • ✓ 歴史のことを調べています
  • ✗ 歴史のことが調べています（が 让"历史"变成调查主体）

修饰名词时变 についての：歴史についての本。

によって（五个用法）

用法意思例句
① 被动施动者被／由ピカソによって描かれた
② 手段通过インターネットによって情報を得る
③ 原因由于事故によって遅れた
④ 差异基准因人而异（最高频）人によって考え方が違う
⑤ 构成由…构成10人によって構成されている
被动里的换位：主动句 ピカソが絵を描いた → 被动 絵がピカソによって描かれた。
即 が → によって，を → が。是换位，不是相加，所以不能说 ピカソがによって。
形态接什么例句
によって后接动词地震によって被害が出た
による后接名词地震による被害
により书面语，同 によって地震により被害が出た
受害被动不能换 によって：✓ 雨に降られた　✗ 雨によって降られた

06最容易混的五组

对比一句话区分
ことにする vs ことになる自己拍板 vs 结果定下来
てくる vs ていく朝我来（做完回来）vs 离我去（做完离开）
あげる／くれる／もらう主语是给的人（前两个）还是收的人（もらう）
について vs のことについて＝复合助词，后面不再加助词；のこと＝名词，必须带 を／が／は
で vs に（な形容词）接形容词用 で（静かでいい）；接动词用 に（静かに話す）

07自测 10 题

先自己做，想不起来再点开答案。全部做完一遍再对，别逐题对。

1. 友達が本を＿＿＿。（我收到书）
くれた　主语是朋友（给的人），受益者是我 → くれる。
2. 私は田中さん＿＿＿教えてもらった。
に　もらう 句型里，施予者用 に（或 から）。
3. 今、駅に着いた＿＿＿です。（刚刚到）
ところ　た形＋ところだ＝刚刚。用 ばかり 也可以，但语气更松。
4. 来月、引っ越す＿＿＿になりました。
こと　动词接 になる 必须先加形式名词 こと。
5. 静か＿＿＿いい部屋ですね。
で　な形容词并列、接形容词时用 で。✗ 静かにいい。
6. 静か＿＿＿話してください。
に　接动词用 に（副词形）。
7. 最近、寒＿＿＿なりました。
く　い形容词接 なる／する 要把 い 变 く。
8. 外を見たら、雨が降って＿＿＿。（开始下雨）
きた　てくる 表"出现／开始"。
9. 一週間＿＿＿いられません。
しか　しか 必须配否定，意为"只能待一周"。
10. 町の歴史＿＿＿調べています。
について　复合助词，自带"关于"，后面不再加 が／を。
若用 のこと 则必须是 歴史のことを調べています。
复习建议：今天做一遍 → 三天后再做一遍自测 → 一周后只看"最容易混的五组"和自测错题。
排序题不必背语感，按"谁能接谁"推：い形容词直接接 / な形容词加な / 名词加の / 动词直接接。
