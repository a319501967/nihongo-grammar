# 日语语法复习归档

每天一份语法总结，按日期倒序归档。`index.html` 是总目录，双击即可打开。

## 线上地址

GitHub Pages 部署后：

```
https://<用户名>.github.io/<仓库名>/
```

（第一次推送后自动生效，手机上存书签即可随时翻。）

## 目录说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 总目录，由脚本自动生成，不要手改 |
| `YYYY-MM-DD.html` | 每天一份的复习页 |
| `更新索引.py` | 扫描目录 → 重建 `index.html` |
| `发布.sh` | 一条命令：重建索引 → 提交 → 推送 |
| `说明.md` | 命名规则、写作模板、复习节奏 |

## 每天新增一份

```bash
# 1. 把当天的复习页存成 YYYY-MM-DD.html 放进本目录
# 2. 一条命令搞定索引 + 提交 + 推送
bash ~/Documents/日语语法/发布.sh
```

只想在本地看，不推送：`python3 ~/Documents/日语语法/更新索引.py`

## 内容结构

- 每节 = 规则表 + 绿色「要点」框 + 红色「易错」框（✗/✓ 对照）
- 末尾 10 道自测，答案用 `<details>` 折叠
- 浅色排版，可直接 ⌘P 打印

详见 [说明.md](说明.md)。
